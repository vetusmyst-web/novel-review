# 规则文件模板

复制本文件，改名为 `<你的规则名>.md`，放进 `rules/` 目录（或 `rules/examples/`），
然后在书籍配置的 `rules` 数组里写上这个文件名（不含 .md）即可生效。**不用改代码。**

---

- 规则名: 规则显示名
- 严重度门槛: 高,中        # 只保留这些严重度的问题（可选值：高、中、低）
- max_tokens: 2000         # 可选，默认 2000
- temperature: 0.2         # 可选，默认 0.2

## Prompt

（在这里写你的审查提示词）

可用占位符（程序会自动替换）：

| 占位符 | 内容 |
| --- | --- |
| `{title}` | 本章标题，如「第03章 风起」 |
| `{text}` | 本章正文全文 |
| `{prev_ending}` | 上一章结尾 600 字 |
| `{setup}` | 书籍配置里 setup_files 列出的设定文件内容拼接 |
| `{genre}` | 书籍配置里的 genre 字段 |
| `{baseline}` | 书籍配置里的 baseline 字段（可选，如分卷时令表） |

## 输出格式要求（必须写在 Prompt 结尾）

```
只输出一个 JSON 对象，不要任何解释文字：

{"problems": [{"type": "问题类型", "position": "章内位置或原文摘录", "desc": "问题描述", "severity": "高|中|低", "suggestion": "建议改法"}]}

没有明确问题就输出 {"problems": []}。宁缺毋滥。
```
